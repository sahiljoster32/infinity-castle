# Infinity Castle Explorer deployment

Target URL: https://sahiljoster32.github.io/infinity-castle/

This bundle contains:
- `index.html` — SEO-optimized interactive experience
- `robots.txt` — crawler rules + sitemap location
- `sitemap.xml` — canonical page sitemap
- `.nojekyll` — serve files directly on GitHub Pages
- `.github/workflows/pages.yml` — official GitHub Pages Actions deployment workflow

If GitHub Pages has never been enabled for the repository, open:
Repository Settings → Pages → Build and deployment → Source: GitHub Actions.
Then push to `main` or run the workflow manually.
